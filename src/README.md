# Sistema de Calificaciones

Sistema de consola desarrollado en Java para gestionar alumnos, materias y calificaciones.

Este proyecto fue creado como práctica de los fundamentos de Java y Programación Orientada a Objetos (POO).

## 🚀 Funcionalidades

- Agregar alumnos.
- Mostrar alumnos registrados.
- Seleccionar un alumno.
- Agregar materias y calificaciones.
- Mostrar las materias de un alumno.
- Calcular el promedio de un alumno.

## 🛠️ Tecnologías

- Java
- ArrayList
- Programación Orientada a Objetos (POO)

## 📚 Conceptos practicados

Durante el desarrollo del proyecto se practican conceptos como:

- Clases y objetos.
- Encapsulamiento.
- Constructores.
- Getters y setters.
- Métodos.
- ArrayList.
- Recorridos con `for-each`.
- Condicionales.
- Ciclos `do-while`.
- `switch`.
- Referencias a objetos.
- Paso de objetos como parámetros.
- Relación entre clases.
